# Obedové menu v okolí FEI STU

Autor: Samuel Hrdlička

Školský projekt na zobrazenie obedového menu reštaurácií
a jedální v okolí FEI STU.

## Vybrané podniky

- Eat & Meet: https://eatandmeet.sk/tyzdenne-menu
- DRAG: https://www.restauracia-drag.sk/restauracia-drag
- Machnáč: https://machnac.sk/denneMenu.html

## Plánované riešenie

Stránka bude vytvorená pomocou HTML, CSS a JavaScriptu.
Použité knižnice budú Bootstrap a jQuery.
Menu sa bude načítavať z lokálnych HTML kópií stránok.

## Použitie AI

Pri tvorbe projektu bol použitý ChatGPT na konzultácie,
návrh riešenia a pomoc s kódom.
